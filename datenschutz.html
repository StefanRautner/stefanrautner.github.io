Grundsatz

Diese Website ist eine statische Seite ohne Benutzerkonten, ohne Kontaktformular, ohne Newsletter und ohne Webanalyse. Es werden keine Cookies gesetzt, keine Profile gebildet und keine Daten an Dritte weitergegeben oder verkauft. Beim Aufruf der Seite werden keine Verbindungen zu externen Servern hergestellt: Schriftarten und alle angezeigten Grafiken liegen auf demselben Server wie die Website selbst.

Lokale Speicherung im Browser

Zur Speicherung Ihrer Anzeigeeinstellungen verwendet die Website den localStorage Ihres Browsers – technisch keine Cookies. Gespeichert werden ausschließlich zwei Werte:

theme
gewähltes Farbschema (hell oder dunkel)
lang
gewählte Anzeigesprache (Deutsch oder Englisch)

Diese Werte verbleiben ausschließlich auf Ihrem Gerät, werden zu keinem Zeitpunkt an einen Server übertragen und enthalten keinerlei personenbezogene Daten. Da es sich um eine von Ihnen selbst angeforderte Funktion handelt, ist hierfür gemäß § 165 Abs. 3 TKG 2021 keine Einwilligung erforderlich. Sie können die Werte jederzeit über die Einstellungen Ihres Browsers löschen.
